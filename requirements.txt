# Runtime dependencies for the deployed Streamlit app.
#
# Every package here is installed on each cold start, so the list is kept to
# what the running app actually imports. Deliberately excluded:
#   torch / sentence-transformers - embeddings are precomputed by ingest.py
#   beautifulsoup4 - only the parser needs it, and the app never parses HTML
#   python-dotenv  - local convenience; Streamlit Cloud injects secrets as
#                    environment variables, and config.py treats it as optional
#
# Install the ingestion extras with: pip install -r requirements-dev.txt

# Streamlit is pinned because Streamlit Cloud reinstalls on every cold start:
# an unpinned app picks up each new release unannounced, and releases remove
# deprecated arguments. 1.64.0 is what the live app ran when this was pinned,
# and CI tests the same version. Upgrade deliberately, with the tests.
